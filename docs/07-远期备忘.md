# 远期备忘（只写形态与约束，不写实现）

## Apple Watch

形态：它本来就是文字游戏。表盘上一次只做一件事：今天的八个价（转表冠滚动）→ 点一种货买卖 → 转表冠选站，按下就是一天。事件是一整屏原文，抬腕就读完。

关键约束：五个数不可能同屏，至少让「欠债」和「剩几天」常驻在顶上；数量输入只能是「最多」和步进；一局四十天要能随时放下，下次抬腕接着走。

## tvOS

形态：十英尺外的账本。左右两页大表，遥控器上下选货、左右决定买进或卖出，长按买到最多；菜单键是「老板来了」。二环图铺在屏幕下缘，焦点沿线路走。

关键约束：没有指针，一切靠焦点，焦点顺序就是信息架构；字要大，一屏仍要放下八行货和五个数；客厅里是别人一起看的，事件页要停得够久。
