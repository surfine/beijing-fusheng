# 审计：时代限制与设计意图

原版界面的每个元素归到两列之一。「时代限制」可以重做；「设计意图」必须留下。右列括号里是它保护的原则（见提示词 core_principles 1–7）。

| 原版元素 | 时代限制（1998–2001 的 MFC 对话框） | 设计意图（留下） |
|---|---|---|
| 一屏六件事（黑市、出租屋、买卖、状态、地铁图、五个机构） | 618×541 固定像素、控件互相挤压 | 同屏本身。看价、看仓、看债、看去哪，是一个决定（3 一屏的经济学） |
| 黑市／出租屋两张 SysListView32 | 灰色表头、可拖列宽、第三列空白、`(001 ` 行号 | 左买右存、货从左流到右的方向感；买进价与黑市价并排（2、3） |
| `==>` `<==` `==>>` `<<==` 四个箭头 | 10×17 像素的小按钮，要先选行再点 | 买进与卖出是两个相反的方向；箭头就是方向（3） |
| 「买多少？」「卖多少？」「现金交易」三连弹窗 | MFC 做数量输入只能弹模态框 | 数量由你定，默认给最多；成交前看得见总价（2） |
| 您的状态：现金／存款／欠债／健康／名声 | 静态文本，红色只在名声 < 60 时出现 | 五个数永远在，欠债每天变（2 数字的残酷） |
| 北京市地铁示意图：十个按钮 | 按钮摆成三行，不是真的环 | 十个真站名；点一个站，一天就没了（1、5） |
| 「我要逛京城」 | 没有第二张图的空间，只能把十个按钮改名 | 同十个地方的地面名字（永安里、方 庄、海淀大街…）；换图不花天数（5） |
| 「老板来了」大按钮 | 橙色位图按钮 | 伸手就能按到，瞬间换屏（7） |
| 银行、医院、邮局、租房中介、网吧 | 底栏五个等宽按钮＋菜单里重复一遍 | 五个真机构，各一句刻薄话（4、5） |
| 机场 | 只在菜单里，点了是 2.0 预告 | 预告文案是作品的一部分，留在菜单里（4） |
| 事件弹窗（北京新闻／我在北京的岁月） | 模态框盖住主窗口，一条一个，连点「确 定」 | 世界打断你，不问你；新闻是别人的口气，日记是「俺」的口气（1、4） |
| 81×102 报纸小图、55×53 灯泡、圆点条 | 256 色、小尺寸、糊 | 四色印刷的小报版面，是全作唯一的图形语言（美术） |
| 15 枚图标 | 来源不一、风格混杂 | 城市天际线＝这游戏；青烧瓶＝一行货（美术） |
| 窗口标题 `北京浮生(%d/40天)` | — | 倒计时就写在标题上（1） |
| 开场「故 事 简 介」＋输入大名 | 一个对话框塞 11 行静态文本 | 进城前先读规矩；「欠村长5400元」是村长的说法（4） |
| Loading：「初始化二环路信息.....」等 5 行 | 假进度，定时器换字 | 不留。它不承载口吻，只是拖时间（6 不加糖的反面：不加戏） |
| 发财之日积月累 | MFC Tip of the Day 模板，内容在外部 Tips.txt（未随 exe 提供），残留 `Some String` | 不留（没有原文可用，不编造） |
| 声音 `sound\*.wav` | — | 本轮全程无声（提示词 anti_patterns） |
| 游戏设置：关闭声音／允许黑客攻击银行网络 | 两个复选框一个对话框 | 「允许黑客攻击银行网络」留作菜单里的一个勾选项（规则开关） |
| 高手榜 score.txt | 外部文本文件 | 本地前十名，默认榜是赖皮张、萧峰、二黑…（5、6） |
| 字体 MS Sans Serif 8pt／System／宋体／Tahoma 混用 | 当年的系统默认 | 不留。只留「密」和「直角」（3） |
| 写作（老板键画面） | System 字体的编辑框 | 原文、假拼写检查、能存盘，全留（7） |
| 关于／寄5分钱／特别声明 | 假链接位图、玩笑按钮 | 文案全留；邮箱用真文本 |
| MFC 灰、3D 边框、对话框单位 | 系统外观 | 不留。窗框交给桌面，内容区用四色 |
