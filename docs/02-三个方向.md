# 三个方向

## 账本

**关键画面。** 蓝底上摆两页白纸：左页「黑  市」，右页「您的出租屋」，中缝是买进、卖出两个箭头和数量。下面一页是「您的状态」五行账，一行一个数，数字右对齐、等宽；旁边是二环线路图，十个站是十个方格。最底一行是五个机构。四十个白圆点横在页眉下，过一天涂掉一个。

**牺牲了什么。** 牺牲了「新」。它的骨架和 2001 年几乎一样，不会让人觉得是一次重新发明；地图也只是线路图，没有城市感。

## 柜台

**关键画面。** 八种货一字排开成一张柜台，每种货一格：上面是今天的价，下面是你屋里的数量，格子里直接有「买」「卖」。状态是柜台上方的一条窄带，车站是柜台下的一排车票。

**牺牲了什么。** 牺牲了「左买右存」的两张表，也就牺牲了老玩家的第一眼。成本价被挤成小字，买进价与黑市价不再并排，账读起来像货架标签；八格等宽也让它滑向卡片流。

## 小报

**关键画面。** 整个窗口是一张小报头版：报头「北京浮生记」，头条是今天的新闻，行情表是报上的「今日黑市行情」栏，状态是右栏的「俺的账」，车站在报脚。每过一天换一版。

**牺牲了什么。** 牺牲了安静。原版大多数日子没有新闻（平均每天不到一条），一张每天都要有头条的报纸，要么天天开天窗，要么逼我编稿子。报纸也把「俺」的日记和别人的新闻混成一种口气。

## 选定：账本

理由，按原则：

- **两秒认出（验收标准）**：老玩家认的是骨架——左黑市、右出租屋、中间箭头、下面五个数和十个站。账本原样留着它；柜台和小报都把它拆了。
- **3 一屏的经济学**：账本天然同屏，不需要分页。
- **2 数字的残酷**：账本的排法（一行一个数、右对齐、每天多出来的利息写在旁边）比卡片或报栏更冷。
- **4 俺的口吻 / 1 一天一次**：新闻和日记不占常驻版面，只在出事那天翻出来盖住交易台；安静的日子就是安静的。
- **小报的东西没有丢**：报纸版面留给「北京新闻」「我的日记」两种事件页，四色与圆点条成为全局语汇。

被否掉的两个方向各留下一样东西：柜台的「一行内完成买卖」用在手机宽度；小报的版式用在事件页。
