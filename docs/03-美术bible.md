# 美术 bible

全作的图形语汇只有 7 枚图标、4 张位图，以及由同一套线条派生的东西（表格的黑栏线、站点方格、圆点）。母版是矢量，由 `tools/build-art.mjs` 写出；`npm run art` 重新生成 `art/` 下的全部文件。应用里用的是 SVG 母版本身，PNG 是交付用的导出。

原版的美术语言是四色印刷的廉价小报，不是像素风。重制还原的是「报纸」：平涂、硬边、粗黑线、网点。

## 1. 规则（全族只有一套）

| 规则 | 值 |
|---|---|
| 母版 | 图标 1024×1024（原版 32px 的 1 格 = 32 单位）；位图长边 2048 |
| 光源 | 一个，在左上 |
| 影 | 轮廓原样复制一份，向右下平移 40 单位，填青 `#00FFFF`，硬边。没有模糊、没有透明度。这是全作唯一的「影」，界面里的环线也用它 |
| 描边 | 黑 `#000000`，40 单位（32px 时 1.25px），直角接头；16px 简化版用 64 单位（16px 时 1px） |
| 填色 | 平涂。没有渐变、高光、玻璃、纹理 |
| 层次 | 要灰就用网点（黑点压白底），不用透明度——只在报纸的照片位用到 |
| 背景 | 透明（位图「今日新闻」「我的日记」「圆点条」自带蓝底，那是画面的一部分） |

原版里这条影子是存在的：4、5、7、10、11 号图标的右缘和下缘都有一条青绿色硬边。重制把它统一成一个方向、一个宽度、一种青。

## 2. 色板

| 名 | 值 | 角色 |
|---|---|---|
| 蓝 | `#0000FF` | 底：报纸位图的底、圆点条、内容区 |
| 白 | `#FFFFFF` | 纸、圆点、窗格 |
| 黄 | `#FFFF00` | 字与亮处：竖排标题、屋顶、灯泡、卡片、钱袋上的 $ |
| 青 | `#00FFFF` | 辅：影、钱袋、透视地板 |
| 黑 | `#000000` | 线：描边、楼、栏线、字 |
| 灰 | `#C0C0C0`／`#808080` | 天空、墙、信封 |
| 红 | `#FF0000` | 太阳、十字、印章 |
| 绿 | `#008000`／`#00FF00` | 钱袋的口、卡片上的方框 |
| 橄榄 | `#808000` | 天际线前景的坡 |

全部是原版 16 色 VGA 盘里出现过的颜色，没有新增。界面用到的角色与深色外观下的取值见 `art/palette.json` 与 `04-规格.md` 第 3 节：深色外观只对调纸和墨，蓝底、黄字、青辅、黑线的关系不动。

**两处与规格文档不一致，以原图为准：**

- 规格把 2 号写成「青烧瓶＋黄裂纹＋绿塞」。放大看，它是一只**钱袋**，「裂纹」是一个「$」。重制按钱袋画（几何不变是第一条验收标准），语义仍是「货物」。
- 规格把 10 号写成「灰软盘」。它是一枚**信封**（右上是邮票框，中间是两行地址）。重制按信封画，文件叫 `letter`，语义从「存档」改为「邮局／高手榜」。本作没有需要「存盘」图标的地方（存档是自动的；老板键的「存 盘」在伪装文档里，不能出现游戏图形）。

### 16px 简化版

每枚图标另有一个 `*-16.svg`：描边加粗到 1px，去掉小于 2px 的细节（窗格、日光、第二行字、白芯、螺口的白环），形状落在 64 单位的网格上。各枚图标的 16px PNG 由简化版导出；32px 以上由母版导出。`hospital` 的母版本身已经够简单，16px 直接用母版。

### 第 15 枚的去向

原版 15 枚图标里，15 号是组 128 的 16×16 小图，画面和 14 号**不是同一张图**的缩小（蓝黑底上几块青白形状，辨认不出内容）。它被 `city-16`（14 号的 16px 简化版）取代。所以账是：保留 6 枚（14、2、5、6、10、11）＋合并 3 枚（1、4、7）＋丢弃 5 枚（3、8、9、12、13）＋取代 1 枚（15）＝15。

## 4. 四张位图

| 文件 | 原版 | 画面 | 用在哪 |
|---|---|---|---|
| `news` | 140（81×102） | 蓝底上一张三栏小报：黑底反白的报头、通栏标题、网点照片位、栏线、豆腐块；右侧竖排黄字「今日新闻」 | 事件页：北京新闻 |
| `diary` | 141（81×102） | 同一张报纸，竖排「我的日记」 | 事件页：我在北京的岁月 |
| `dots` | 170（186×31） | 蓝底一排等距白圆点 | 页眉的四十个圆点由它派生（过一天涂掉一个） |
| `bulb-floor` | 112（55×53） | 黄灯泡（黑色「!」灯丝）、五道黄色短光、灰螺口，立在一块青线透视地板上 | 交付母版；本轮界面未使用（见下） |

说明：

- 报头写「北京真理报」，是游戏原文里出现的报名（《北京真理报》社论）。原图的报头糊成一团，认不出字。
- 原图最右有一条暗红色竖带，不在四色角色里，重制成黑带。
- 报纸位图里的字用系统宋体渲染；SVG 母版依赖系统字体，PNG 导出不依赖。
- `bulb-floor` 原本属于「发财之日积月累」。那个窗口取消了（提示内容在外部 Tips.txt，未随 exe 提供），所以这张图只作为母版交付，没有放进界面，不为它硬造一个用处。
- 透视地板：六条青线都通向下方同一个消失点，三条横线越近越短，不做密网。

## 5. 禁用项

渐变、投影（模糊的）、玻璃、拟真金属、纹理、做旧、CRT 扫描线、噪点、霓虹、圆角、人物、吉祥物、场景插画、3D 渲染。原版 6 号灯泡的抖动渐变是唯一一处「原版有、重制去掉」的效果，理由见规格文档第 6 节 D 条。

## 7. 验收（如实）

- 缩回 32px 与原版并排：轮廓、朝向、色位对得上（见对照图）。差别：`city` 多了一圈黑框和青影（为了与全族一致），画面因此比原版略小；`house` 的侧墙山尖比原版低一格。
- 16px：七枚都认得出；`city-16` 只剩两高一矮三栋楼和一轮红日。
- 只在本机用 `rsvg-convert` 与 Chromium 看过；没有在 Windows 或 Android 上检查字体回退后的报纸位图。
