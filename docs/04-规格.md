# 规格

方向：账本（见 `02-三个方向.md`）。每条后面的 ⟨n⟩ 是它保护的原则编号。

## 1. 主窗口解剖

窗框、标题、菜单栏由桌面画，跟随系统外观。下面只说 iframe 里的内容区。默认窗口 1064×744（内容区刚好够桌面版式的 1024 宽），可缩放；窗口再小就滚动，不裁掉任何一行货；内容区是一个 12 列栅格，列间距 8px，外边距 10px，所有边角为直角。

## 2. 字体层级

只用系统字体，不带字体文件。

| 层级 | 用途 | 规格 |
|---|---|---|
| 报头 | 窗口内标题、事件页栏名 | 20px／粗，中文 `"Songti SC", "SimSun", "Noto Serif CJK SC", serif` |
| 正文 | 文案、表格 | 14px／1.5，中文 `"PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif` |
| 账 | 一切数字 | 14px，`ui-monospace, "SF Mono", Menlo, Consolas, monospace`，`font-variant-numeric: tabular-nums`，右对齐 |
| 注 | 行内状态、增量 | 12px，同正文 |

事件原文用正文层级全文显示，不截断、不缩成一行 ⟨4⟩。最小字号 12px。

## 3. 色彩

内容区是「游戏画面」，用本作四色，不走 kit token（明确声明：这是游戏画面的一部分）；窗框、菜单、状态条不碰。

| 角色 | 浅色外观 | 深色外观 | 用在哪 |
|---|---|---|---|
| 蓝（底） | `#0000FF` | `#0000C8` | 内容区底、页眉、被选中的行 |
| 纸 | `#FFFFFF` | `#0A0A14` | 表格与账页 |
| 墨（线） | `#000000` | `#FFFFFF` | 字、栏线、站点方格的边 |
| 黄（字） | `#FFFF00` | `#FFFF00` | 蓝底上的标题、涨跌与欠债的标记 |
| 青（辅） | `#00FFFF` | `#00FFFF` | 持有标记、图标的硬边影、次要注记 |
| 灰 | `#808080`／`#C0C0C0` | `#808080`／`#404040` | 缺货、买不起、不可用 |

深色外观只把「纸」和「墨」对调，蓝底、黄字、青辅、黑（白）线的角色不变。黄和青不直接压在白纸上当文字（对比不够），在纸面上它们只做色块，上面压黑字。

## 4. 组件与状态

### 商品行（黑市）

一行 30px（手机 44px）。从左到右：货物符号、商品名、行内注记、黑市价格。七种状态在行内读出，不靠悬浮提示：

| 状态 | 行内表现 |
|---|---|
| 正常 | 黑字，价格右对齐 |
| 持有 | 商品名后青色块「屋里 37」；出租屋那一行同时显示买进价格与每个盈亏 |
| 暴涨 | 价格前黄色块「涨」，价格加粗（当天行情事件 ×n） |
| 暴跌 | 价格前黑底白字「跌」（当天行情事件 ÷n） |
| 买不起 | 价格为灰，行尾「钱不够」 |
| 仓库满 | 表头右侧「屋满」，所有行的买进不可用，原因写在买卖栏 |
| 违法货（禁书、假白酒） | 商品名本身带着原文括号（「（禁书）」「（剧毒！）」）；持有时出租屋行尾注「卖出 名声−7／−10」 |
| 缺货（附加） | 行为灰，价格处「——」。原版把缺货的行直接删掉；这里留行位，八种货位置固定，看价更快 |

选中的行整行蓝底白字（深色外观同）。

### 成本价与现价

保留两张表（黑市／出租屋），不合成一张盈亏表：左买右存是老玩家的第一眼。盈亏写在出租屋行的第二行小字里：`现在 512，每个 +110`；这一站没人收时写 `这里没人收`。⟨2、3⟩

### 买卖栏

选中一行后，中栏显示商品名、数量框（默认「最多」）、原文提示（`%ld元人民币,最多可以买%d个`）、总价。两个主按钮上下排列、箭头方向相反：`买 进  ==>` 指向出租屋，`<==  卖 出` 指向黑市。`==>>` 买到最多，`<<==` 全部卖出。**一步成交，没有二次确认** ⟨1、3⟩。

### 状态账

五行，标签用原文（`现 金` `存款：` `欠 债` `健康：` `名声:`，原样的空格与冒号）。数字等宽右对齐。欠债行每天在数字右侧写出当天多出来的钱（`+550`），黄底黑字，留到下一次过天 ⟨2⟩。健康 < 20、名声 < 60 时该行黑底白字。不做进度环、不做大数字卡片。

### 地铁示意图

二环画成一个直角环，西边伸出一段到苹果园；黑线 3px，站是 44px 高的方格按钮，当前站蓝底黄字。站位照原版按钮的三行摆法。「我要逛京城」把十个站名换成地面名字、标题换成「北京市地面示意图」，按钮变「我要进地铁」，不花天数 ⟨5⟩。

### 事件页

换站之后如果这一天出了事，交易台那一格翻成事件页：左边是报纸位图（「今日新闻」或「我的日记」），右边是原文全文，下面一个按钮（新闻「确 定」，日记「关上日记本」）。一天多条时按原版顺序一条一条来，右上角写「1／3」。事件页挡住买卖（世界打断你），但不挡状态账和地图；状态数在事件页出现的同时已经变了 ⟨1、2、4⟩。安静的日子不出事件页。

### 办事机构的单子

银行、医院、邮局、租房中介、网吧都在交易台那一格里展开成一张单子（标题、原文、数量框、两个原文按钮），不另开窗口。

### 老板键

按下「老板来了」（或 Esc），整个内容区**同一帧**换成白底黑字的《关于做好本月工作的一些具体想法》，窗口标题换成「写作」。无过渡、无淡入。「存 盘」经 `files.export` 真的存出一份文本；「拼写检查」给出那两句建议。再按 Esc 或「确 定」同一帧切回。期间游戏不接受任何输入 ⟨7⟩。

### 结局

交易台那一格变成一页结账单：现金、存款、欠债、净值四行，下面是原文那一句，再下面是「高手榜」十行。没有动画、没有颜色变化 ⟨6⟩。

## 5. 动效原则

- 会动的只有两样：过天时页眉圆点涂掉一个（120ms），欠债增量出现（无动画，直接出现）。
- 事件页、单子、老板键、结局：**不动**，直接换。
- 「减少动态」打开时，圆点也不动。
- 没有缓动曲线表，因为没有第三样会动的东西 ⟨6⟩。

## 6. 键盘映射（桌面）

| 键 | 作用 |
|---|---|
| Tab／Shift+Tab | 依次：黑市表 → 买卖栏 → 出租屋表 → 地图 → 机构 |
| ↑ ↓ | 在表内移动选中行 |
| ← → | 在黑市表与出租屋表之间换（同一种货） |
| B／S | 买进／卖出（按数量框里的数） |
| M／A | `==>>` 买到最多／`<<==` 全部卖出 |
| Enter | 事件页与单子的主按钮 |
| Esc | 有单子时关单子；否则老板来了；老板画面里再按切回 |
| G | 我要逛京城／我要进地铁 |

站点和机构是普通按钮，Tab 到、空格或回车按下。焦点环 2px 黄色外框加 1px 黑线，在蓝底和纸面上都看得见。

## 8. 四档取舍

| 宽度 | 布局 | 取舍 |
|---|---|---|
| ≥1024 | 上面的解剖图 | 无 |
| 768–1023 | 同一栅格；买卖栏收到两张表下面成一条横栏；账与图左右各半 | 表行高仍 30px；买卖仍是选行 → 按一下 |
| 390（以及横放的手机） | 单列：页眉 → 状态账（五个数排成一行两排）→ 一张合并的货表（商品、黑市价格、屋里数量；点一行在行下展开买卖条）→ 十站 5×2 方格 → 五个机构一行 | 两张表合成一张（柜台方向留下的那一样）；地铁图不画线，只留站序；盈亏小字只在展开的行里出现 |
| 320 | 同 390，站名与机构名缩到 12px，圆点条换成「3/40天」文字 | 圆点条让位给文字 |

手机上触控目标不小于 44px；不依赖 hover；`viewport` 不允许缩放页面之外的缩放手势改变布局（`width=device-width, initial-scale=1`，内容不溢出）。横屏（高度不到 450 的窄屏）时货表在左，状态、车站、机构在右，整页可滚动。

**5 秒决定**：390 宽时，价格、屋里数量、现金在同一屏；点一行（1 次）、点「==>>」（1 次）、点一个站（1 次），三次触摸完成「看价 → 买 → 换站」。

平台的手机档位选 **phone: 2**（内容就是屏幕）：这是一个整屏的游戏，手机上没有理由再套一层浮动窗口的边框去挤掉一行货。

## 9. 无障碍

- 两张表是真 `<table>`，有 `<caption>` 与 `scope`；行内状态是文字，不只是颜色。
- 事件页是 `role="alertdialog"`，出现时焦点移到它的按钮，读屏会读出全文。
- 状态账是 `<dl>`；欠债增量带 `aria-label`（「比昨天多 550」）。
- 圆点条对读屏隐藏，天数由标题文字给出。
- 所有交互都有键盘路径（第 6 节）。
